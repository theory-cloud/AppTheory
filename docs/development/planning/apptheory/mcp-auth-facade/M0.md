## Default-semantics recommendation (up front)

**Facade-scoped default flip:** an `AppTheoryMcpServer` that attaches the OAuth facade defaults to
`runtime-bearer`; a plain transport server keeps `iam`; `unauthenticatedMcp` is replaced by an explicit
`transportPosture` selection whose `none-public` value is never a default. See `DEFAULT_SEMANTICS.md`.

## Open decisions for the operator

1. `DEFAULT_SEMANTICS.md` — accept the facade-scoped default flip (recommended) vs an additive posture vs
   replacing `unauthenticatedMcp` semantics; and accept removing `unauthenticatedMcp` (no shim).
2. `DEFAULT_SEMANTICS.md` — whether `none-public` may compose with `rootAuthorizationServerDiscovery` when both
   are explicitly declared public (today the construct throws).
3. `FRAMEWORK_VS_POLICY.md` — framework defaults vs app override for refresh lock/coalesce/grace numbers;
   whether the challenge alias bridge ships at all; whether legacy-client adoption gets a named seam.
4. `DEFENSE_IN_DEPTH.md` — whether `originReachability: direct` is allowed under `runtime-bearer`; the exact
   bounded dimension set for the denial metric; whether access logging is mandatory under `runtime-bearer`.
5. `CONFORMANCE_KIT.md` — posture marker location (CFN metadata vs jsii assertion); whether the kit's runtime
   layer ships as a published testkit helper.
6. `MINIMAL_CONSUMER.md` — callback path default vs required config; scope vocabulary shape.
7. `RELEASE_NOTE_CORRECTION.md` — whether the operator edits the immutable 6.0.0 GitHub Release body; where the
   durable correction record lives.
8. `CANDIDATE_BUILD_INTERFACE.md` — derive `source_date_epoch` from the commit; the lab stage allowlist.
9. `UNVERIFIED.md` — U11: whether Autheory could mint per-route issuers (an Autheory-side question, not an
   AppTheory change).
